# SPORT VAULT — V10

**COLLECT THE GAME.**

Prototype de plateforme de collection sportive, avec FOOTVAULT comme premier univers football.

## Fonctionnalités V10

- Comptes et sessions
- Packs et tirages côté serveur
- Économie (FOOTCOINS, Gems, XP, niveaux)
- Cartes uniques avec UUID, rareté, édition et numéro de série
- Collection
- Album Ligue 1 2026/27 (prototype)
- Progression par club et compétition
- Récompenses d'album côté serveur
- Marketplace
- Échanges entre joueurs
- Classements

## Lancer en local

```bash
npm start
```

Puis ouvrir `http://localhost:3000`.

## Prototype

Les joueurs, clubs et contenus sont fictifs dans cette version. Les données persistantes sont stockées localement dans `data.json` (non versionné).

Pour une production multi-sports : PostgreSQL, sessions persistantes, sécurité renforcée et séparation frontend/API seront à mettre en place.
