# SPORT VAULT — nouvelle base

**COLLECT THE GAME.**

Reconstruction propre de SPORT VAULT. FOOTVAULT sera le premier univers, puis la plateforme pourra accueillir d'autres sports.

## V0.1

- Architecture Node simple et lisible
- Authentification serveur
- Sessions persistantes quand PostgreSQL est disponible
- PostgreSQL comme stockage cible
- Design premium unifié
- Pages de base : Accueil, Collection, Album, Packs, Mon Vault, Market

## Principes

Le navigateur ne sera jamais la source de vérité pour l'économie ou les cartes. Les comptes, soldes, sessions et futurs objets de collection seront gérés côté serveur.

## Local

```bash
npm install
npm start
```

Puis ouvrir `http://localhost:3000`.
